# 광덕고 3D 캠퍼스 · SMASH 광덕고

2023년 평면도를 바탕으로 만든 광덕고등학교·광덕중학교 캠퍼스 3D 모델과 부수기 게임입니다.
건물 위치·운동장·도로는 위성사진에 맞춰 배치했고, 지붕·기둥·간판 같은 겉모습은 현장 사진(2026년 11월)을 보고 다듬었습니다.

## 실행
1. VS Code에서 이 폴더(`gwangdeok-campus`)를 엽니다. (파일 → 폴더 열기)
2. 확장 프로그램 **Live Server**를 설치합니다. (폴더를 열면 설치 추천이 뜹니다)
3. `index.html`을 오른쪽 클릭 → **Open with Live Server** → 브라우저에서 3D 모델이 열립니다.
   게임은 주소 끝을 `game.html`로 바꾸면 됩니다.

인터넷이 연결돼 있어야 합니다. (three.js와 글꼴을 CDN에서 불러옵니다)

## 수정하는 법
`src/` 안의 파일을 고친 뒤 VS Code 터미널(Ctrl+`)에서 다음을 실행하면 `index.html`, `game.html`이 새로 만들어집니다. (Node.js 필요)

```
node build.mjs
```

| 파일 | 내용 |
|---|---|
| `src/data.js` | 건물 도면 데이터 — 건물 위치(X0, Z0, rot), 층별 방 이름·용도·좌표(m) |
| `src/generator.js` | 방 배치로 벽·칸막이·문·바닥·지붕·난간을 자동 생성 |
| `src/textures.js` | 벽돌·창문·지붕 텍스처와 재질 |
| `src/furniture.js` | 방 용도별 가구 (교실 책상, 기숙사 침대 등) |
| `src/site.js` | 땅·운동장·도로·나무·주택가·간판·태양광 등 주변 환경 |
| `src/core.js` | 렌더러, 카메라, 조명, 지형(체육관 언덕) |
| `src/model.js` | 3D 모델 화면 (이름표, 층별 단면, 시점 버튼) |
| `src/game.js` | 게임 (부서지는 조각, 도구, 점수) |
| `src/head-*.html` | 각 페이지의 HTML·CSS |
| `models/gwangdeok-campus.glb` | 블렌더·유니티용 3D 모델 파일 |

### 방 하나 고치기 예시
`src/data.js`에서 `RM('이름','용도',u0,v0,u1,v1)` 한 줄이 방 하나입니다. 좌표는 각 도면 시트 기준(m)이고,
건물마다 `rot`(도면 위쪽이 가리키는 방위)과 `X0, Z0`(도면 원점의 실제 위치)로 캠퍼스에 배치됩니다.
캠퍼스 좌표는 m 단위이고 x는 동쪽, z는 남쪽입니다. 축은 건물 방향에 맞춰 정북에서 시계 방향으로 10.25° 돌아가 있고, 덕린관을 기준점으로 위성사진에 맞췄습니다.
